# Чистый репозиторий с виртуальным окружением

### 1. Почему venv не нужно коммитить?

Папку venv не нужно загружать в GitHub, потому что она содержит виртуальное окружение с установленными библиотеками. Она занимает много места, и каждый разработчик может создать своё окружение самостоятельно.

### 2. Что будет, если другой разработчик склонирует репозиторий без venv? Как восстановить окружение?

Если другой разработчик скачает проект без venv, он сможет создать новое виртуальное окружение командой:

`python -m venv venv`

Затем установить необходимые библиотеки из файла requirements.txt:

`pip install -r requirements.txt`

### 3. Зачем нужен requirements.txt и как он связан с .gitignore?

Файл requirements.txt хранит список установленных библиотек и их версий. С его помощью можно установить необходимые зависимости на другом компьютере.

Файл .gitignore исключает виртуальное окружение из Git, а requirements.txt, наоборот, добавляется в репозиторий.
